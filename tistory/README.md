# 티스토리 게시 대기 글

브라우저를 쓰는 Claude가 매일 오전 11시경 이 목록을 읽고, 티스토리에 아직 없는 글 중 맨 위 1편을 발행합니다.
새 글은 매일 아침(11시 전) 목록 맨 아래에 추가됩니다.
글 파일: `# 제목`, `# 카테고리`, `# 태그`, `# 본문` 칸으로 나뉩니다.

## 발행 규칙
- 제목·카테고리·태그·본문을 그대로 옮긴다. 카테고리가 블로그에 없으면 새로 만든다.
- 본문의 `## `는 제목2 서식, `- `는 목록, `**굵게**`는 굵은 글씨로 넣고 기호 자체는 남기지 않는다.
- 공개 설정은 '공개'. 전화번호 010-5364-6186과 홈페이지 주소는 고치지 않는다.
- 티스토리 외의 사이트에는 아무것도 올리지 않는다.

## 사진 규칙
- 사진은 사장님 컴퓨터의 현장 사진 폴더(브라우저 채팅에 연결됨)에서 가져온다.
- 글 파일에 `[사진: 설명]` 줄이 있으면, 폴더에서 그 설명에 가장 맞는 사진을 직접 보고 골라 그 자리에 넣는다.
- `[사진: ...]` 줄이 없는 글도 글 주제에 맞는 현장 사진 1~3장을 골라 본문 중간에 넣는다.
- 사람 얼굴, 차량 번호판, 다른 업체 상호가 크게 보이는 사진은 쓰지 않는다.
- 이미 티스토리 글에 쓴 사진은 다시 쓰지 않는다.
- 맞는 사진이 없거나 넣기에 실패하면 사진 없이 발행하고, 보고할 때 알려 준다.
