# 브런치 게시 대기 글

브라우저를 쓰는 Claude가 이 목록 위에서부터 읽고, 브런치에 아직 없는 글만 발행합니다.
새 글은 목록 맨 아래에 추가합니다.

## 사진 규칙
- 사진은 사장님 컴퓨터의 현장 사진 폴더(브라우저 채팅에 연결됨)에서 가져온다.
- 글 파일에 `[사진: 설명]` 줄이 있으면, 폴더에서 그 설명에 가장 맞는 사진을 직접 보고 골라 그 자리에 넣는다.
- `[사진: ...]` 줄이 없는 글도 글 주제에 맞는 현장 사진 1~3장을 골라 본문 중간에 넣는다.
- 사람 얼굴, 차량 번호판, 다른 업체 상호가 크게 보이는 사진은 쓰지 않는다.
- 이미 브런치 글에 쓴 사진은 다시 쓰지 않는다.
- 맞는 사진이 없거나 넣기에 실패하면 사진 없이 발행하고, 보고할 때 알려 준다.
