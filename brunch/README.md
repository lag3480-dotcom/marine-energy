# 브런치 게시 대기 글

브라우저를 쓰는 Claude가 이 목록 위에서부터 읽고, 브런치에 아직 없는 글만 발행합니다.
새 글은 목록 맨 아래에 추가합니다.

## 사진 규칙
- 글 파일에 `[사진: images/파일이름.jpg]` 줄이 있으면 그 자리에 사진을 넣는다.
  사진 주소는 이 폴더 기준이다. 예: .../brunch/images/파일이름.jpg
- 사진 넣기에 실패하면 그 줄은 빼고 글을 발행한 뒤, 보고할 때 "어느 글 몇 번째 사진을 못 넣었는지" 알려 준다.
- 사진 줄이 없는 글은 사진 없이 발행한다.
